# Windows / ZIP setup

The binary `gradle/wrapper/gradle-wrapper.jar` is not included in this repository.

After downloading the ZIP (or cloning), run this in the project folder:

```
curl -L -o gradle/wrapper/gradle-wrapper.jar https://raw.githubusercontent.com/gradle/gradle/v8.10.2/gradle/wrapper/gradle-wrapper.jar
```

Or open the project in Android Studio, which can regenerate the Gradle wrapper for you.
